Turn a How Might We into rough, editable wireframes with your own AI agent.

01Connect your agent

Run the command for your agent in a terminal, then restart its session. Requires Node.js 22.12+ and the local bridge package.

Claude Code
claude mcp add hmw-diverger -- npx -y hmw-diverger-mcp
Codex
codex mcp add hmw-diverger -- npx -y hmw-diverger-mcp

Source checkout: build the repository, then replace npx -y hmw-diverger-mcp with node /absolute/path/bridge/dist/index.js. The npm commands require a published release.

02Pair this bridge

Ask your agent for the HMW Diverger pairing token from figma_status({includePairingToken:true}), then paste it here. Pair again after restarting the bridge.

Kept only while this plugin window is open. Paste JSON also works without pairing.
